# Otros proyectos de Saúl Muñoz Pedreros

## AiLicitación

AiLicitación es una plataforma SaaS para proveedores del Estado, enfocada en licitaciones de Mercado Público con IA. Busca licitaciones, órdenes de compra y Compra Ágil, y usa IA para decir si conviene postular, evaluar o descartar. AiLicitación usa Next.js, TypeScript, Gemini, la API de Mercado Público y Google OAuth.

## Aura

Aura es un motor de navegador escrito desde cero en Rust, que abarca red, parseo, estilos, layout, renderizado y scripting. Aura tiene unas 4.200 líneas de código y 89 tests en verde. Usa Rust, Tokio, html5ever, Boa, egui y wgpu.

## Flowlai

Flowlai genera diagramas BPMN desde lenguaje natural. El usuario describe un proceso en palabras y obtiene un diagrama BPMN 2.0 válido y editable, exportable a BPMN, XML, SVG, PNG y Draw.io. Flowlai usa React 19, TypeScript, Vite, bpmn-js, Gemini y Clerk.

## Veronica

Veronica es un asistente de Google Workspace. Reúne Gmail, Calendar, Tasks y Drive en una sola interfaz, con varias cuentas a la vez y un asistente que entiende el contexto del usuario. Veronica usa TypeScript, Google APIs, OAuth2, Gemini y shadcn/ui.

## Oil Drilling Dashboard

Oil Drilling Dashboard es una herramienta de análisis de perforación con IA. El usuario sube el Excel de una perforación y obtiene gráficos de profundidad, DT, GR y composición de roca, más un chat para consultar los datos. Usa Next.js, PostgreSQL, Claude, GPT-4 y Docker.

## DeepLabScan

DeepLabScan es un proyecto de detección de objetos con YOLO. Es un pipeline completo de visión por computadora, desde los datos crudos hasta la evaluación del modelo, sin pasos manuales. DeepLabScan usa Python, PyTorch, Ultralytics, OpenCV y scikit-learn.

## LicitacionesOnline

LicitacionesOnline es una plataforma para publicar y gestionar licitaciones públicas y privadas, con roles para administradores, postulantes y evaluadores. Usa Next.js 16, Node.js, PostgreSQL, Prisma y Docker.

## WorkMech

WorkMech es una app de gestión para talleres que empezó como proyecto a medida y fue el antecedente directo de Tallertrack. WorkMech usa Flutter, Dart, Firebase y Fintoc.
